# Digital Communication Laboratory Python Codes

This repository contains Python implementations of Digital Communication laboratory experiments based on the 5th Semester Digital Communication Laboratory (EC105401EC). The programs are developed for educational purposes to help students understand fundamental digital communication concepts through simulation and visualization.

## Laboratory Experiments

### Experiment 1
- Natural Sampling
- Sample and Hold Sampling
- Flat-top Sampling

### Experiment 2
- Reconstruction of Sampled Signal

### Experiment 3
- Carrier Modulation Schemes
  - Amplitude Shift Keying (ASK)
  - Phase Shift Keying (PSK)
  - Frequency Shift Keying (FSK)

### Experiment 4
- Pulse Width Modulation (PWM) and Demodulation

### Experiment 5
- Pulse Position Modulation (PPM) and Demodulation

### Experiment 6
- Pulse Amplitude Modulation (PAM) and Demodulation

### Experiment 7
- AM Wave Analysis using GNU Radio (SDR)

## Software Requirements

- Python 3.x
- NumPy
- Matplotlib
- SciPy (if required)
- GNU Radio (for SDR-based experiments)

## Objectives

- Understand the principles of digital communication.
- Simulate communication systems using Python.
- Visualize analog and digital signals.
- Compare theoretical concepts with simulation results.
- Develop practical programming skills in communication engineering.
